About this mod

ترجمة شاملة

تعريب كامل للعبة Game of Thrones: Kingsroad (صراع العروش: الطريق الملكي) — القوائم، المهام، الحوار، المعدات، والمهارات.

لهجة خليجية

تحديث تلقائي

المثبت يفحص GitHub تلقائياً. إذا فيه تحديث جديد، ينزل ملف التعريب بدون ما تحتاج EXE جديد.

شرح التثبيت والتحديث

Installation guide

  1. أغلق اللعبة تأكد إن Kingsroad مو شغالة قبل التثبيت.
  2. حمّل وافتح المثبت ملف TSA-Kingsroad-Arabic.exe من ملف ZIP.
  3. تحذير Windows More info → Run anyway (الملف غير موقّع حالياً).
  4. حدّد مسار Steam اكتشاف تلقائي أو تحديد يدوي لمجلد اللعبة.
  5. إعدادات اللعبة Language: English — ثم ابدأ New Game أو كمل حفظك.
  6. التحديث إذا ظهر «تحديث جديد» → اضغط «تحديث الآن».

مهم قبل اللعب

  • التعريب يشتغل مع اللغة English في إعدادات اللعبة.
  • لازم تثبيت Steam ونسخة Windows من اللعبة.
  • زر «إزالة» في المثبت يحذف ملف التعريب فقط — ما يمس اللعبة الأصلية.
  • للدعم والتحديثات: Discord TSA

أسئلة شائعة

FAQ

هل أحتاج EXE جديد مع كل تحديث؟

لا. بعد أول تثبيت، المثبت ينزل التحديثات من GitHub تلقائياً. افتح المثبت واضغط «تحديث الآن».

Why English in game settings?

The mod replaces English string files. Set in-game Language to English for Arabic text to appear correctly.

هل يعمل مع Epic أو Game Pass؟

حالياً المثبت مضبوط على Steam. إذا كانت نسختك على منصة ثانية، تواصل معنا على Discord.

كيف أزيل التعريب؟

افتح المثبت واضغط «إزالة». أو احذف ملف ProjectT-Windows_P.pak من مجلد Paks في اللعبة.

جاهز للعب؟

حمّل المثبت، ثبّت التعريب، وانضم لمجتمع TSA على Discord.
