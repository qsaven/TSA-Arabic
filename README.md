# TSA-Arabic

مستودع التحديثات التلقائية للانشر TSA Community.

---

## لانشر التعريبات العربية

لانشر موحّد يدير تعريبات TSA لأكثر من لعبة، ويتحدث تلقائياً بدون ما تحتاج تحمّل نسخة جديدة يدوياً.

### الألعاب المدعومة حالياً

- **Game of Thrones: Kingsroad** — تعريب كامل
- **Palworld** — تعريب + خط عربي
- **Crimson Desert** — تعريب كامل
- **Big Ambitions** — تعريب كامل

### مميزات اللانشر

- تحديث تلقائي للتعريبات من GitHub بدون ما تُعيد تحميل اللانشر
- تحديث ذاتي للانشر نفسه بشريط تقدّم داخل التطبيق
- دعم تعدد الألعاب من نافذة واحدة
- واجهة عربية احترافية

### التثبيت

حمّل آخر إصدار من صفحة الـ Releases:

[**⬇ تحميل اللانشر**](https://github.com/qsaven/TSA-Arabic/releases/latest)

## هيكل المستودع

| المجلد | الوصف |
|--------|-------|
| `launcher/version.json` | إصدار اللانشر + رابط التحديث الذاتي |
| `update/` | ملفات تحديث تعريب Kingsroad |
| `update/palworld/` | ملفات تحديث تعريب Palworld |
| `catalog/games.json` | كتالوج الألعاب المعروض داخل اللانشر |
| `docs/` | موقع TSA Community (GitHub Pages) |
| `downloads/` | روابط تحميل مباشرة |
